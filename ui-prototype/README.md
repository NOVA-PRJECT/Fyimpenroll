# FYIMP Portal UI concept

Open `index.html` directly in a browser. The prototype starts at sign-in and follows the first-login consent step before opening the role dashboard. It uses only HTML, CSS, and JavaScript; it does not connect to the live app or backend.

Choose a demo account to sign in, accept the sample consent screen on first sign-in, and then use Sign out to return and choose another role:

- Student
- Course Teacher
- Teaching Staff
- Head of Department
- Campus Director
- Super Admin

The demo password for all accounts is `Demo@2026`. Navigation, sample tables, filters, modal forms, and action feedback are included to make the role flows reviewable. All names, counts, events, and actions are sample data.
