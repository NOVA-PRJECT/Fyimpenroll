## Shared contracts and unresolved policy

- Class identity is catalogue course + host campus + academic year + semester, carried by stable timetable entry IDs for dated attendance. A shared catalogue course does not merge campus deliveries.
- Flat registration slots 1–8 establish current enrollment. `selections` stores reconciled snapshots, not an alternative enrollment source. Existing missing history remains visibly unavailable.
- Attendance CAS uses dated timetable entry + expected revision. Statement percentages count recorded present/absent periods and disclose that denominator.
- Graduation candidate records survive student/Auth deletion; promotion request receipts preserve the original candidate list. Retry uses recorded IDs, never arbitrary missing users.
- Refresh invalidation on logout prevents an in-flight client refresh from replaying a request; provider cookie/revocation behavior still requires browser testing.
- Degree matrix, approved academic-level mapping, term/makeup rules, attendance denominators, GPS retention, export-before-deletion policy, final templates, co-teaching/travel/fairness rules and staff roster reach remain institutional decisions.
